# Real approved labels

Five labels from the Public COLA Registry (https://www.ttbonline.gov/colasonline/publicSearchColasBasic.do). TTB approved each one, so the app should not report a rule failure or a disagreement on any of them. Public records.

The values typed for each label (`cases.json`) come from the record's application page (TTB F 5100.31 as filed). That form has no box for class or type, alcohol content or net contents, so only product type, source, brand name and fanciful name are typed. The label is checked against the rules for everything else. The fanciful name for Woodford Reserve is cut off in the record itself ("BUY THE BARRE") and is typed as filed.
